# 隋唐大运河修正 (Sui-Tang Grand Canal Fix)

## 📌 Mod 简介
本 Mod 旨在修正《十字军之王3》（CK3）在 1.18“鹤”版本（包含“东亚与帝国”DLC）中，中国超级工程“大运河”（`grand_canals`）走向出现的重大历史穿越错误。

原版游戏中，大运河直接套用了**元、明、清时期“裁弯取直”后的京杭直线大运河**（直接走鲁西南曹州、单州、濮州直上河北沧州、德州、北京幽州），完全遗漏了唐宋两代帝国的运河命脉——**东都洛阳**与**东京开封（汴梁）**。

本 Mod 将游戏内的大运河体系彻底还原为符合 9 至 13 世纪真实历史的**隋唐大运河**格局，重构了四大渠段，让东都洛阳、东京汴梁与江淮、江南真正通过运河紧密连结！

## ✨ Mod 特色
1. **历史还原**：洛阳与开封作为隋唐宋的核心都城，在完成对应运河工程后，将实打实获得运河增益（发展度增长、补给上限提升、旅行危险度降低）。
2. **完美兼容原版机制**：
   - 保留原版 `dlc_tgp_grand_canal_X_region` ID，100% 兼容工部尚书互动、丝绸之路催化剂与所有 DLC 事件。
   - 不修改任何核心脚本逻辑文件（如 `00_great_project_types.txt`），最大限度避免 Mod 冲突。
3. **沉浸式双语本地化**：
   - 提供简体中文与英文支持。
   - 区域名称更新为历史上的著名渠名（江南运河、山阳渎、通济渠、永济渠）。
   - 重构大运河超级工程背景描述，再现隋炀帝敕建、唐宋漕运通达的宏大史诗。
