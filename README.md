# 天朝大型工程修复 (Celestial Great Projects Fix)

## 📌 Mod 简介
本 Mod 针对《十字军之王3》（CK3）在 1.18“鹤”版本与“东亚与帝国”（TGP）DLC 中，中华天朝区域的两大超级工程——**“大运河”**与**“万里长城”**中存在的严重历史穿帮、AI 逻辑死锁与作用域 Bug 进行全面深度修复。

整合两大核心模块：
1. **隋唐大运河路线修正**：去直取弯，将洛阳（东都）与开封（汴京）重新确立为大运河核心中枢。
2. **万里长城大型工程逻辑修复**：杜绝 AI 在关中无脑发起死锁空工程，修复全部 35 处长城段落在天朝官僚制下的归属判定，解除主建筑师死锁。

---

## 🏰 模块一：万里长城大型工程逻辑修复 (Great Wall Fix)

原版中“加固万里长城”（great_wall）存在严重的脚本逻辑设计漏洞，导致原版天朝剧本极度影响游戏体验：

### 1. 发起条件校验（解决 AI 关中无脑发起死锁）
- **原版 Bug**：发起条件仅检查了“处于和平状态”与“未规划长城”，未校验领内是否真正拥有未满级（1–3级）的长城段落。导致京兆府留后/工部尚书等内阁要员在长安频繁发起长城工程，但领内根本无段落可修，导致工程永久卡死、无法取消。
- **本 Mod 修复**：在发起条件（can_start_planning）与 AI 意愿（i_will_do）中增加前置判断：顶级领主（皇帝）领内必须存在等级为 1–3 级且尚未升至满级（4级）的长城。AI 在无可用升级段落时发起意愿降为 0。

### 2. 作用域判定修复（解决 35 处长城段落“无法贡献”Bug）
- **原版 Bug**：全部 35 个可选长城段落（walls_01 至 walls_35）的展示条件写为 province_owner ?= { top_liege = root.top_liege }。在天朝官僚制或未分封男爵领的情况下，province_owner 为空（由伯爵直辖），或者 GUI 界面渲染时的 oot 作用域无法解析为角色，导致界面上所有长城段落均显示为“无法贡献”或直接不显示。
- **本 Mod 修复**：为全部 35 处长城段落增加三重作用域回退保护：
  `pdx
  OR = {
      province_owner ?= { top_liege = scope:owner.top_liege }
      county.holder ?= { top_liege = scope:owner.top_liege }
      scope:owner.top_liege = {
          any_realm_county = { this = prevprev.county }
      }
  }
  `
  彻底保证无论段落是由男爵直辖、伯爵兼领，还是官僚节度使管辖，只要处于帝国领内，均能正常显示并允许投资建设。

### 3. 主建筑师前置死锁解除 (Master Builder Fix)
- **原版 Bug**：主建筑师任命条件硬性要求 exists = scope:great_project.var:any_funded_provinces（必须先有地块获得资助）。玩家/AI 若先选择委任主建筑师，按钮将永久锁死。
- **本 Mod 修复**：只要领内存在可升级段落，随时允许资助主建筑师，避免操作顺序引发死锁。

### 4. 官员发起工程有效性保护 (is_valid)
- **原版 Bug**：工程有效性原本检查 scope:owner = { any_realm_county = { ... } }。工部尚书或非皇帝官员发起时，其自身直属封地往往不在塞北长城，导致工程发起瞬间即被系统判定无效直接作废。
- **本 Mod 修复**：统一改为校验 scope:owner.top_liege 领内，确保朝廷官僚发起长城工程时稳健推进。

## ✨ 兼容性与技术特性
- **成就兼容**：大型工程与地理区域修改会更改游戏校验码（Checksum），不支持铁人成就。
- **存档兼容**：可中途加入新开存档；若已有存档中已经发起了长城工程，修复补丁将立即生效解除贡献限制。
- **DLC 依赖**：设计用于 1.18+ 及《东亚与帝国》（TGP）DLC 大型工程机制。
- **文件覆盖范围**：
  - common/great_projects/types/00_great_project_types.txt（修复 great_wall 类型）
  - map_data/geographical_regions/geographical_region.txt（修正运河 4 个子区域）
  - localization/（双语本地化与提示说明）
